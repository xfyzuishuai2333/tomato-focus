番茄专注 · Tomato Focus

简洁高效的番茄钟专注计时器，帮助你保持专注、追踪工作节奏

Edge 浏览器扩展 · 免费开源

📦 GitHub 仓库 🚀 在线体验

✨ 核心功能

⏱️

三种计时模式

专注（25分钟）、短休（5分钟）、长休（15分钟）一键切换

📊

今日统计

完成番茄数、专注分钟数、连续天数一目了然

🔔

桌面通知

番茄完成或休息结束时自动推送浏览器通知

⚙️

自定义时长

专注时长 15~50分钟、休息时长自由配置

🔄

自动循环

专注完成后自动进入休息，无需手动切换

💾

数据持久化

设置和统计数据自动保存，跨天连续追踪

📥 安装方法

1

打开扩展管理

在 Edge 浏览器地址栏输入 edge://extensions/

2

开启开发者模式

点击右上角「开发者模式」开关，打开扩展调试权限

3

加载扩展

点击「加载解压缩的扩展」，选择项目文件夹

4

开始使用

浏览器工具栏出现番茄图标，点击即可开始专注计时
